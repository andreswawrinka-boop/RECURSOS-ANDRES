TÉCNICAS DE CONTEO EN PROBABILIDAD

Cuándo usar cada fórmula, con ejemplos claros.

¿QUÉ USAR? — 2 preguntas

  1. ¿Importa el orden de los elementos? → SÍ = permutación · NO = combinación
  2. ¿Se puede repetir un elemento? → SÍ = con repetición · NO = sin repetición
1 · PERMUTACIÓN SIN REPETICIÓN
Orden SÍ importa · NO se repite
Fórmula
P(n,r) = n! / (n−r)!
Ejemplo
De 10 corredores, ¿cuántas formas hay de asignar oro, plata y bronce?
P(10,3) = 10! / 7! = 10·9·8 = 720
Se usa
podios ordenar rankings contraseñas sin repetir
2 · PERMUTACIÓN CON REPETICIÓN
Orden SÍ importa · SÍ se repite
Fórmula
PR(n,r) = nr
Ejemplo
PIN de 4 dígitos (0–9), se pueden repetir:
104 = 10 000 combinaciones posibles
Se usa
claves placas de auto códigos lanzar dados
3 · COMBINACIÓN SIN REPETICIÓN
Orden NO importa · NO se repite
Fórmula
C(n,r) = n! / [r!·(n−r)!]
Ejemplo
De 20 estudiantes, ¿cuántos comités de 3 se pueden formar?
C(20,3) = 20! / (3!·17!) = 1 140
Se usa
comités lotería muestras equipos manos de cartas
4 · COMBINACIÓN CON REPETICIÓN
Orden NO importa · SÍ se repite
Fórmula
CR(n,r) = C(n+r−1, r)
Ejemplo
Con 5 sabores de helado, ¿cuántos conos de 3 bolas se pueden armar (permitiendo repetir sabor)?
CR(5,3) = C(7,3) = 35
Se usa
helados selección con reemplazo inventarios

REGLAS RÁPIDAS

· Principio multiplicativo: si un evento tiene a formas y otro b formas → a·b resultados totales.

· Factorial: n! = n·(n−1)·(n−2)···1 · Por definición 0! = 1.

· "AB ≠ BA" → permutación · "AB = BA" → combinación.

· Palabras con letras repetidas: P = n! / (n₁!·n₂!···). Ej: "CASA" = 4!/2! = 12.

MÉTODOS NUMÉRICOS

Error numérico · Raíces · Mínimos cuadrados · Funciones kernel

1 · ERROR NUMÉRICO
Cuantificar la diferencia entre el valor real y el que la computadora calcula.
Tipos de error
TipoOrigenEjemplo
TruncamientoSe corta una serie infinitaUsar sólo los 3 primeros términos de sen(x) = x − x³/6 + x⁵/120 − …
RedondeoAritmética finita del computador1/3 ≈ 0.3333 (se pierden infinitos dígitos)
InherenteDatos de entrada con incertidumbreMedir una masa con balanza de ±0.01 g
De propagaciónUn error se amplifica en operaciones sucesivasRestar dos números casi iguales
Fórmulas clave
Error absoluto Ea = | xreal − xaprox |
Error relativo Er = Ea / | xreal |   (×100% = %)
Cifras significativas correctas Si Er ≤ 0.5 × 10−n   →   hay al menos n cifras significativas
Ejemplo
Se sabe que π = 3.14159265… y se aproxima como 3.1416. Ea = |3.14159265 − 3.1416| = 7.3 × 10⁻⁵ Er = 7.3 × 10⁻⁵ / 3.14159 ≈ 2.3 × 10⁻⁵ = 0.0023 % → Aproximación con 4 cifras significativas correctas.
Cuándo importa: en cálculos iterativos (raíces, EDO), donde el error se acumula y puede volver inútil el resultado. Se usa el error relativo como criterio de parada: si Er < tolerancia → detener.
2 · RAÍCES DE ECUACIONES
Encontrar x tal que f(x) = 0 cuando no hay solución analítica.
Métodos principales
MétodoFórmula / reglaRequisitosConvergencia
Bisección xr = (a+b)/2 f(a)·f(b) < 0 Lenta pero segura (lineal)
Falsa posición xr = b − f(b)(a−b)/[f(a)−f(b)] f(a)·f(b) < 0 Más rápida que bisección
Newton-Raphson xn+1 = xn − f(xn)/f′(xn) f′(x) ≠ 0, buen valor inicial Cuadrática (rapidísima)
Secante xn+1 = xn − f(xn)(xn−xn−1)/[f(xn)−f(xn−1)] Dos valores iniciales Superlineal (~1.618)
Ejemplo — Newton-Raphson
Hallar la raíz de f(x) = x² − 2 (o sea √2), partiendo de x₀ = 1.5. f′(x) = 2x x₁ = 1.5 − (1.5² − 2) / (2·1.5) = 1.5 − 0.25/3 = 1.4167 x₂ = 1.4167 − (0.00695) / (2.8333) = 1.41422 x₃ = 1.41421356…   ← ya coincide con √2 en 8 dígitos → 3 iteraciones para 8 cifras exactas (convergencia cuadrática).
Criterio de parada: se detiene el método cuando |xn+1 − xn| / |xn+1| < ε (tolerancia, típ. 10⁻⁶), o cuando se alcanza el número máximo de iteraciones.
3 · MÍNIMOS CUADRADOS
Encontrar la mejor curva que se ajusta a un conjunto de datos con dispersión.
Idea central

Se busca minimizar la suma de los cuadrados de los residuos (distancias verticales entre datos observados y curva ajustada):

S = Σ (yi − ŷi)²   →   mínimo
Regresión lineal simple   y = a + b·x
Pendiente b = [n·Σxiyi − Σxi·Σyi] / [n·Σxi² − (Σxi)²]
Intercepto a = ȳ − b·x̄
Coeficiente de determinación R² = 1 − SSres/SStot  →  (0 = mal ajuste, 1 = perfecto)
Ejemplo
Datos: x = [1, 2, 3, 4, 5], y = [2, 4, 5, 4, 5]. n = 5 · Σx = 15 · Σy = 20 · Σxy = 66 · Σx² = 55 b = (5·66 − 15·20) / (5·55 − 15²) = 30 / 50 = 0.6 a = 20/5 − 0.6·(15/5) = 4 − 1.8 = 2.2 → Recta ajustada: y = 2.2 + 0.6·x
Extensiones: ajuste polinómico (y = a₀ + a₁x + a₂x² + …), regresión múltiple (varios predictores) y no-lineal (linealizando por transformaciones logarítmicas o exponenciales).
4 · FUNCIONES KERNEL
Medir similitud entre puntos SIN transformarlos explícitamente a un espacio de mayor dimensión.
Definición formal
K(x, y) = ⟨φ(x), φ(y)⟩

Un kernel es una función que devuelve el producto interno de dos puntos ya transformados a un espacio de mayor dimensión, sin necesidad de calcular la transformación φ explícitamente. Esto se llama truco del kernel (kernel trick).

Kernels más usados
KernelFórmulaCuándo se usa
Lineal K(x,y) = x · y Datos linealmente separables (texto, alta dimensión)
Polinómico K(x,y) = (x·y + c)d Datos con interacciones no lineales de grado d
RBF / Gaussiano K(x,y) = exp(−‖x−y‖² / 2σ²) Datos con estructura local, no lineales, alta flexibilidad
Sigmoide K(x,y) = tanh(α·x·y + c) Análogo a red neuronal de una capa
Ejemplo — kernel RBF
Sean x = (1, 2) y y = (3, 4), con σ = 1. ‖x − y‖² = (1−3)² + (2−4)² = 4 + 4 = 8 K(x, y) = exp(−8 / 2) = exp(−4) ≈ 0.0183 → Los puntos son "poco similares" (valor cercano a 0). Si estuvieran muy cerca, K se acercaría a 1.
¿Dónde se aplican?
SVM (máquinas de soporte vectorial) Clasificar datos no lineales trazando un hiperplano en el espacio kernel.
Regresión kernel (Nadaraya-Watson) Estimar y suavizar funciones sin asumir forma paramétrica.
KDE (kernel density estimation) Estimar la densidad de una variable aleatoria de forma no paramétrica.
PCA kernel Reducción de dimensionalidad no lineal.
Condición de Mercer: para que una función sea un kernel válido, su matriz de Gram (Kij = K(xi, xj)) debe ser simétrica y semidefinida positiva. Esto garantiza que existe un espacio φ correspondiente.

RESUMEN — ¿QUÉ USO Y CUÁNDO?

· Error: siempre reportarlo (absoluto para magnitud, relativo para calidad); tolerancia decide cuándo parar un iterativo.

· Raíces: bisección si necesito seguridad; Newton si tengo f′(x) y buen x₀; secante si no tengo derivada.

· Mínimos cuadrados: para ajustar modelo a datos; R² dice qué tan bien se ajusta.

· Kernel: cuando los datos NO son lineales pero quiero aplicar métodos lineales — RBF es la primera opción por defecto.
